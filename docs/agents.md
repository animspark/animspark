# Using AnimSpark with your coding agent

AnimSpark does not ship its own agent. You bring one — Claude Code, Codex, Cursor or anything
else that can edit files and run commands — and the `anim` engine gives it what it needs to
make a film: a workspace layout, a manual, and commands that check, show and render the
result on your machine.

There are two ways for an agent to drive the engine, and they combine freely:

- **The shell.** The agent runs `anim check`, `anim look`, `anim render` … like any other
  command. Every command answers in JSON, so an agent can read the result directly.
- **MCP.** `anim mcp` serves the same commands as tools over stdio. The advantage: `look`
  returns the frame *as an image*, so the agent sees the picture without a separate file read,
  and the tools show up in the agent's tool list with their parameters documented.

## 1. Start a film

```sh
anim new "A 30-second explainer about how tides work" --dir tides --sec 30
cd tides/code
```

`anim new` creates:

| Path | What it is |
| --- | --- |
| `film.json` | The running order: tracks and clips. Starts empty. |
| `mg/` | Your scenes — React components animated with GSAP. |
| `assets/` | Media. Put your own files in `assets/upload/`. `assets/index.jsonl` is the (read-only) catalogue. |
| `skills/` | Manuals. `skills/animspark/mg/SKILL.md` is the scene contract; read it before writing `mg/`. |
| `CLAUDE.md`, `AGENTS.md` | The editor's manual (same text under both names). Claude Code reads `CLAUDE.md`; Codex and Cursor read `AGENTS.md`. Regenerated by `anim new` — do not edit. |
| `../runtime/task.json` | This job's parameters: stage size, target length, language. |

Then start your agent **in `tides/code`** and give it the brief. The manual tells it the loop:
edit files → `anim check` → `anim look` → fix → … → `anim render`.

While it works, you can watch:

```sh
anim preview          # opens http://127.0.0.1:4173 — follows every save
```

## 2. Connect the engine over MCP (optional, recommended)

The server is `anim mcp`: stdio, no network listener, no configuration. It uses its working
directory as the default workspace, and every tool also accepts an explicit `workspace` path.

### Claude Code

```sh
cd tides/code
claude mcp add animspark -- anim mcp
```

`--` separates Claude's options from the server command. Add `--scope project` to write the
entry to `.mcp.json` in the repository (shared with collaborators) or `--scope user` to have it
everywhere. The same thing by hand, in `.mcp.json`:

```json
{
  "mcpServers": {
    "animspark": { "command": "anim", "args": ["mcp"], "timeout": 600000 }
  }
}
```

`timeout` (milliseconds) is the per-tool-call limit; renders of long films can take minutes.
Docs: <https://code.claude.com/docs/en/mcp>

### Codex

```sh
codex mcp add animspark -- anim mcp
```

or in `~/.codex/config.toml`:

```toml
[mcp_servers.animspark]
command = "anim"
args = ["mcp"]
# The default tool timeout is 60 s — too short for `render`.
tool_timeout_sec = 600
```

Codex starts the server in the directory you launch it from; pass `workspace` to the tools (or
set `cwd = "/path/to/tides/code"` in the table) if that is not the film.
Docs: <https://learn.chatgpt.com/docs/extend/mcp?surface=cli>

### Cursor

`.cursor/mcp.json` in the project (or `~/.cursor/mcp.json` for all projects):

```json
{
  "mcpServers": {
    "animspark": {
      "type": "stdio",
      "command": "anim",
      "args": ["mcp"]
    }
  }
}
```

Cursor asks you to approve a new MCP server the first time it sees it — accept the prompt in the
editor, or run `cursor-agent mcp enable animspark` for the Cursor CLI. `cursor-agent mcp list-tools
animspark` then lists the engine's tools. If the film is not the folder you opened, point the tools
at it with the `workspace` argument.
Docs: <https://cursor.com/docs/context/mcp>

> If `anim` is not on your `PATH` (e.g. you run it from a checkout), use
> `"command": "node", "args": ["/path/to/animspark/packages/engine/bin/anim.mjs", "mcp"]`.

### The tools

| Tool | Does | Same as |
| --- | --- | --- |
| `new` | Create a workspace. Later calls without `workspace` use it. | `anim new` |
| `check` | Validate film.json, compile and smoke-render the scenes. `timeline: true` adds the evaluated timings. | `anim check` |
| `look` | Contact sheet (`from`/`to`/`fps`), one frame (`at`) or the sound (`sound: true`). Returns the PNG as an image plus the JSON receipt. | `anim look` |
| `render` | The mp4 under `.anim-out/`. | `anim render` |
| `clip` | One block over a transparent background (webm / prores / png / mp4). | `anim clip` |
| `preview_url` | Starts the live preview once per workspace and returns its URL. | `anim preview` |
| `audio_voice`, `audio_tts`, `audio_sfx`, `audio_music`, `audio_asr`, `image_search`, `image_gen`, `font_search` | Media. Listed only while a provider is set up — see [cloud.md](cloud.md). `quote: true` prices a call without running it. | `anim audio tts` … |

Errors come back as tool errors carrying the CLI's own message (for `check`, the
`{"status":"Fail","errors":[…]}` JSON), so the agent can fix and retry. Long calls send
progress notifications when the client asks for them. The server speaks MCP 2024-11-05
through 2025-11-25 (the `initialize` handshake) and 2026-07-28 (per-request metadata,
`server/discover`).

## 3. Media: voices, sound, images

Checking, looking and rendering never need an account. Voice-over, sound effects, music,
transcription, image search/generation and fonts run on a media provider (use your own web tools for research):

```sh
anim login            # AnimSpark Cloud — API keys at https://animspark.com
anim credits          # balance and prices
anim audio voice --prompt "calm documentary narrator"
anim audio tts --text "The moon pulls the sea." --voice <voiceId> --out line1
```

…or with your own OpenAI / ElevenLabs key, or with files you already have. Details in
[cloud.md](cloud.md).

## Tips for agents (and the people steering them)

- **Check after every round of edits.** A failing `check` blocks `render`, and the preview keeps
  showing the last passing version.
- **Look before you declare victory.** A contact sheet for pacing, `look --at` for small type
  and banding; `look --sound` for the mix.
- **Quick listen:** `anim render --fps 4 --width 480` renders in seconds with identical audio.
- **Narration timing:** synthesized speech arrives with word timings; animate with
  `cue(vo, 'phrase')` from `@animspark/runtime` instead of hand-typed seconds.
