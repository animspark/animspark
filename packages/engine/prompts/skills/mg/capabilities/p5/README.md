# Generative art and particles (p5)

Generative art, noise fields and particles. Use p5's instance mode; load it dynamically, only after mounting in the browser.

When you need it, read [Create a canvas that can be sampled repeatably](APIs/p5.md). It contains a component example you can drop into a scene, the parameters, and the library's limits.

Rules, density, color and spatial scale together determine the image. Build a readable graphic system first, then add particles; complex text layout still belongs in the DOM.
