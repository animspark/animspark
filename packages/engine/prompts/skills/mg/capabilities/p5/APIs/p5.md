# p5

| Item | Usage |
| --- | --- |
| Loading | Dynamic import only: `import('p5').then(({ default: P5 }) => new P5(sketch, hostDiv))`, and register that promise with `registerFilmPending` so `anim look` and the render wait for it. The MG build first evaluates the module in an environment without a DOM; a top-level `import p5 from 'p5'` accesses `window` immediately and fails. Do not import `@animspark/p5` |
| Loop | Call `noLoop()` in `setup`; `const t = useLocal()`, and whenever `t` changes, write it into a ref and call `inst.redraw()`; `draw` reads the current second from the ref. When async loading completes, also redraw at that moment |
| Determinism | At the start of every `draw`, call `randomSeed` / `noiseSeed`; for evolution over time, feed `t` into the noise coordinates instead of advancing through a `random()` sequence |
| Canvas | Take the size from the host div (filling the whole frame = stage size); for a transparent background, use `p.clear()` instead of `background()` |
| Unmount | `inst.remove()`, otherwise the canvas and listeners leak onto the page |

The `Example` below can go into the current MG scene as a child component.

```tsx
import { useLayoutEffect, useRef } from 'react';
import { registerFilmPending, useLocal } from '@animspark/runtime';


export function Example() {
  const host = useRef<HTMLDivElement>(null);
  const sketch = useRef<{ redraw: () => void; remove: () => void } | null>(null);
  const t = useLocal();
  const now = useRef(t);
  useLayoutEffect(() => { now.current = t; sketch.current?.redraw(); }, [t]);
  useLayoutEffect(() => {
    let gone = false;
    registerFilmPending(import('p5').then(({ default: P5 }) => {
      if (gone || !host.current) return;
      sketch.current = new P5((p: any) => {
        p.setup = () => { p.createCanvas(host.current!.clientWidth, host.current!.clientHeight); p.noLoop(); };
        p.draw = () => {
          const u = now.current;
          p.randomSeed(7); p.noiseSeed(7);
          p.background(16, 18, 24); p.noStroke();
          for (let i = 0; i < 120; i++) {
            const a = p.noise(i * 0.13, u * 0.25) * p.TWO_PI * 2;
            const r = 120 + p.noise(i * 0.31) * 380;
            p.fill(198, 242, 78, 150 + p.noise(i) * 100);
            p.circle(p.width / 2 + Math.cos(a) * r, p.height / 2 + Math.sin(a) * r, 10 + p.noise(i * 0.7, u) * 26);
          }
        };
      }, host.current);
      sketch.current.redraw();
    }));
    return () => { gone = true; sketch.current?.remove(); sketch.current = null; };
  }, []);
  return <div ref={host} style={{ position: 'absolute', inset: 0 }} />;
}
```
